## 2. 关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 版本来源 | **只认 tag** | API 的 `tag_name` 就是发布版本；Cargo 版本常忘改，曾导致"打 0.5.1 却发 0.5.0" |
| 是否保留 feed | **保留** | API 不签名、不绑定 product/platform、无文件清单；feed 是签名契约 |
| 是否保留 `.sha256` | **保留** | GitHub 有 digest 但 Gitee 镜像没有；WinGet/Scoop/手工下载都认旁置文件 |
| 配置位置 | **编译期** | 发布只一个 exe，用户改不了、不会丢；调试用 `--config` 覆盖 |
| 缓存位置 | `%LOCALAPPDATA%\GenericUpdater` | 安装目录保持干净；不可写时回退 `.app-update` 并打日志 |
| 清单位置 | 安装目录隐藏文件 `.update-files.json` | 清缓存/搬目录后仍能正确删除旧版本文件 |
| 跳过状态 | `state.json` 字段 | 不再生成 `skipped-version.txt` 这类文件 |
| 24h 内再次打开 | 用缓存提示"有更新" | 不能因为不联网就假装"已是最新" |
| 启动探测 | 拉起后 3 秒进程存活 | 不写标记文件、不需要客户端配合；代价是 3 秒后才崩不会回滚 |
| 更新器自更新 | 运行中先改名 `*.old-<pid>` | Windows 锁运行中的镜像；改名字允许，下次启动清理 |
| 提权 | `ShellExecuteW("runas")` 重启自身 | 只在安装目录不可写时触发 |
| 签名方案 | RSA-PSS 3072 / SHA-256 / salt 32 | 与 snow-shot 信封同构，便于互相借鉴、工具链通用 |
| 签名触发 | CI 检测到 secret 才签 | 本地/无密钥时仍可跑通链路，但 `require_signature` 会强制拦截明文 |

## 3. 明确不做的事

| 项 | 原因 |
|---|---|
| 增量更新 | 用户明确说先不做；整包下载更简单可靠 |
| Authenticode 证书 | 需要购买；代码侧只能把包做"不那么可疑"，不能替代证书 |
| 常驻 broker / 服务 | 当前提权场景只覆盖"目录不可写"，不值得引入常驻进程 |
| 断电 fsync 级 journal | 概率极低，`--clean` 可兜底 |

## 4. 踩过的坑（都已在代码里修掉）

1. **PowerShell 5.1 读 UTF-8 无 BOM 脚本**会按 GBK 解析，中文直接语法错误
   → 所有 `.ps1` 改成 UTF-8 with BOM；密钥生成改用 PS 5.1 可用的手工 PKCS#1 编码。
2. **`ExportPkcs8PrivateKeyPem` 在 .NET Framework 不存在** → 手工编码 PEM。
3. **CI 把 `notes` 变成数组**（`git log` 输出是字符串数组）→ `-join` 后再 `Trim`。
4. **`CREATE_NO_WINDOW` 启动子进程**被沙箱判"隐藏窗口子进程" → 更新器改 GUI 子系统。
5. **启动时多拉一次 `--recover`** → 恢复并入 `--check`。
6. **`version.txt` 运行时写入**导致"独占打开文件"行为 → 改成由新包直接替换。
7. **`started.flag` 标记**时序问题导致误回滚/重启两次 → 改成 3 秒进程存活探测。
8. **包里的 `README.txt`** 被系统用记事本打开，沙箱记了 11 条 notepad 行为
   → 发布包只留 exe + version.txt。
9. **手动 Run workflow 会占用 Cargo 版本号当 tag**，和上一次撞号（v0.5.5 / v0.5.8）
   → 正式发版用 tag 触发；手动触发前先改 Cargo 版本。

| GUI 全链路 | 0.2.0 → 0.3.0 只重启一次，窗口数 = 1 |
